# IPA Desktop

**Поиск, скачивание и установка приложений для iPhone на Windows, macOS и Linux.**

Приложение на C#, Avalonia и .NET 11 с очередями загрузки и установки, наборами по App Store ID и управлением локальными IPA. Вход и скачивание выполняет **ipatool**, работу с iPhone — наш отдельный комплект **device-tools**.

**[Скачать для Windows, macOS и Linux](https://github.com/iamdarkls/IPA-Desktop/releases/latest)** · [История изменений](https://github.com/iamdarkls/IPA-Desktop/releases) · [Сообщить об ошибке](https://github.com/iamdarkls/IPA-Desktop/issues)

## Быстрый старт

Скачайте ZIP для своей платформы из [последнего релиза](https://github.com/iamdarkls/IPA-Desktop/releases/latest). Среда .NET уже входит в архив.

| Платформа | Какой архив выбрать | Как запустить |
| --- | --- | --- |
| Windows x64 | `-Windows.zip` | Распакуйте ZIP, запустите `IPA-Desktop.exe`. Для iPhone установите Apple Devices или Apple Mobile Device Support. |
| macOS 15+ с Apple Silicon | `-macOS-arm64.zip` | Распакуйте ZIP, перетащите `IPA-Desktop.app` в «Программы» через Finder и откройте оттуда. |
| macOS 15+ с Intel | `-macOS-x64.zip` | Распакуйте ZIP, перетащите `IPA-Desktop.app` в «Программы» через Finder и откройте оттуда. |
| Linux x64 (Ubuntu 24.04+) | `-Linux-x64.zip` | Распакуйте ZIP с сохранением прав, запустите `IPA-Desktop/IPA-Desktop`. Системные зависимости и USB описаны в [инструкции для Linux](Docs/PLATFORMS.md#linux). |

Войдите в Apple Account для поиска и скачивания. Для установки подключите разблокированный iPhone, подтвердите доверие и выберите нужное устройство. Готовые IPA можно устанавливать без входа. Для нескольких приложений используйте **«Наборы» → «Подготовить и установить…»**.

## Поиск и загрузка

- Ищите по названию или числовому **App Store ID**, нажимая Enter или **«Найти»**.
- Одинарный клик выделяет строку; **двойной клик** или **«Добавить»** добавляет приложение в нижнюю очередь. Она сохраняется между поисками. Крестик × убирает один элемент, **«Очистить»** — весь выбор.
- По умолчанию скачивается последняя версия. **«Версии»** и **«Все версии…»** позволяют выбрать другие, добавить несколько версий или указать известные ID вручную. Сведения о совместимости загружаются по запросу и могут отсутствовать.
- **«Скачать (N)»** последовательно обрабатывает очередь. Внизу показаны текущее приложение, оставшиеся операции и доступный прогресс.

Скорость в МБ/с **приблизительная**: она измеряется по росту временного IPA, поэтому буферизация влияет на показания. После 100% ipatool ещё может подготавливать файл — дождитесь завершения. Доступность приложений и версий зависит от аккаунта и сервисов Apple.

## Установка наборов

Во вкладке «Наборы» отметьте наборы, выберите iPhone и нажмите **«Подготовить и установить…»**. Мастер проверяет Apple Account, предлагает готовые IPA этого аккаунта и подготавливает недостающие, используя кэш при совпадении архива. В финальном подтверждении видны устройство, аккаунт, версии и источник каждого IPA. Если связь прервётся, после восстановления можно продолжить с оставшихся на том же iPhone. **«Следующий клиент»** завершает сессию: прежняя очередь доступна через «История клиентов», а IPA, кэш и наборы остаются на месте.

## Файлы и устройство

1. Подключите и разблокируйте iPhone, подтвердите доверие компьютеру. Телефон появится автоматически: один iPhone выбирается сам, при нескольких выберите нужный по имени.
2. При необходимости отфильтруйте IPA по **Apple Account**: все, конкретный аккаунт или «Без данных об аккаунте». Аккаунт определяется из самого IPA; фильтр **не переключает сессию входа**.
3. Добавьте файлы в нижний список двойными кликами или кнопкой **«Выбрать все (N)»** — она добавляет все IPA текущего фильтра без повторов.
4. Нажмите **«Установить (N)»** и проверьте выбранное устройство в подтверждении.

**Выбранные IPA сохраняются при смене фильтра.** Счётчик «вне фильтра» показывает скрытые выбранные файлы: они тоже участвуют в установке и удалении. Перед работой только с другим аккаунтом очистите нижний список.

**«В корзину (N)»** находится справа от кнопок выбора и установки и перемещает файлы в корзину после подтверждения. Приложения на iPhone при этом сохраняются. **«Добавить IPA…»** импортирует внешние файлы, **«Обновить»** перечитывает папку. Сведения, обновление списка и повторы доступны в меню **«Ещё»** рядом с соответствующим блоком.

### Статус iPhone и общая очередь

В карточке iPhone показаны отсутствие подключения, ожидание доверия, проверка, готовность или потеря связи. «Готов к установке» появляется после проверки доверия и идентификатора устройства; перед отправкой IPA связь проверяется снова. Кнопка рядом позволяет проверить или восстановить соединение.

Вкладка **«Очередь»** объединяет результаты скачиваний и установок. Для каждой строки видны приложение, версия (для загрузки — ID версии или «последняя доступная»), прогресс и результат. Проценты появляются только при получении метрики от утилиты. Передача 100% не означает успех, пока утилита не завершила операцию.

При обрыве выполненные элементы сохраняются, остальные отмечаются отдельно. Выберите строку нужной очереди и нажмите **«Продолжить оставшиеся»**. Готовые IPA не повторяются; для установки нужны тот же iPhone, тот же способ подключения и восстановленная связь. При продолжении программа один раз читает список приложений на исходном iPhone. Совпавшие Bundle ID, версия и сборка отмечаются готовыми; неподтверждённые IPA предлагаются к ручному повтору. Перезапуск всей очереди автоматически не выполняется.

История очереди сохраняется в `operation-queue.json` между запусками; последние записи журнала ограничены по объёму. После перезапуска подтвердите исходный аккаунт или восстановите связь с тем же iPhone. Прерванные операции автоматически не запускаются. Файл содержит пути IPA, идентификатор телефона и хеш аккаунта; пароли и токены туда не записываются. «Ещё» → «Сбросить историю» сохраняет резервную копию файла перед очисткой. Выбор IPA и наборы управляются отдельно; переход в очередь не меняет выбранные файлы.

### Приложения iPhone и проверка результата

В карточке iPhone откройте **«Приложения на iPhone»** рядом с проверкой связи. Таблица показывает версии, сборки и App Store ID, если iOS возвращает их в метаданных. Записи без ID нельзя автоматически добавить в загрузку. `Placeholder` может означать сгруженное, загружаемое или незавершённое приложение; для их чтения обновите device-tools до **1.0.5+**.

После обрыва выберите прерванную установку во вкладке «Очередь» и нажмите **«Проверить на iPhone»**. Нужны исходный неизменённый IPA и тот же подтверждённый телефон. Совпадение Bundle ID, известной версии и сборки позволяет предложить пропуск повтора; окончательное решение подтверждается пользователем. Unknown/placeholder не отмечается успешной установкой.

### История покупок и сеть

Общее меню **«Ещё» → «История покупок»** читает текущую сессию и запрашивает последние 90 дней, выбранный год или всю историю. Вся история запрашивается только после отдельного подтверждения. Список очищается при смене аккаунта; в очередь загрузки добавляются только распознанные приложения iOS с ID. Удалённые приложения доступны лишь пока Apple разрешает их повторную загрузку.

**«Настройки» → «Сеть и прокси»** задаёт системный маршрут, прямое подключение или HTTP/HTTPS/SOCKS5-прокси без сохранения его пароля. Системный режим учитывает переменные окружения и настройки Windows. Маршрут применяется к входу и командам ipatool; настройки сети не сбрасывают запреты и паузы аккаунта. Диагностика делает отдельный HTTPS HEAD без учётных данных. Проверка сертификатов не отключается.

### Установка по Wi-Fi — экспериментально

Сначала подключите iPhone по USB и подтвердите доверие. В Apple Devices включите **«Показывать это устройство при подключении к Wi-Fi»**, в iTunes — синхронизацию по Wi-Fi ([инструкция Apple](https://support.apple.com/guide/devices-windows/sync-content-over-wi-fi-mchl388b22c3/windows)).

Подключите компьютер и телефон к одной локальной сети. В программе включите **«USB + Wi-Fi (экспериментально)»** и выберите автоматически появившуюся строку с подписью **Wi-Fi**. Подсказки доступны через **«Wi-Fi: помощь»**. Список проверяется каждые 3 секунды между операциями; выбранный телефон и транспорт сохраняются. При отключении выбранного iPhone программа не выбирает вместо него другой телефон. При обрыве установки автоматического переключения на USB и повтора нет; сначала проверьте результат на телефоне. Режим требует проверки на физическом устройстве.

## Наборы и хранилище

**Наборы хранят ID и названия приложений**, без привязки к аккаунту, телефону, IPA или версии. После смены аккаунта можно скачать тот же набор под новым пользователем.

- **Создать или дополнить:** выберите приложения в поиске, в поле **«Набор»** введите имя или выберите существующий и нажмите **«Добавить в набор»**. Также доступна кнопка **«Сохранить из поиска»**.
- **Использовать несколько:** во вкладке **«Наборы»** отметьте нужные наборы и нажмите **«В очередь скачивания»**. Приложения объединятся без повторов по ID.
- **Изменить:** выберите один набор и откройте **«Редактировать набор…»**. Удаление набора не удаляет скачанные IPA.

Здесь же показан размер хранилища. **«Выделить старые версии»** ищет устаревшие копии отдельно для каждого Apple Account. Проверьте выбор и нажмите **«Удалить выбранные копии»** — файлы попадут в корзину после подтверждения.

## Настройки, ошибки и обновления

Откройте **«Настройки» → «IPA Desktop» → «Проверить версию»**. На Windows ipatool и инструменты iPhone обновляются отдельно, с возможностью отката. На macOS и Linux они входят в пакет приложения.

**Если Mac показывает `AppTranslocation` или `Read-only file system` при обновлении**, закройте IPA Desktop, скачайте новый ZIP для своего процессора и замените `IPA-Desktop.app` через Finder в папке «Программы». IPA, настройки и наборы хранятся в профиле отдельно. Подробный порядок установки и обновления есть в [инструкции по платформам](Docs/PLATFORMS.md#обновление-и-инструменты).

После операции появляется плашка результата. **«Подробнее…»** открывает отчёт, **«Повторить ошибки»** запускает только неудачные элементы. Последний отчёт доступен через общее меню **«Ещё» → «Итог операции»**. Отмена останавливает текущую работу, сохраняя уже завершённые операции. На Windows и macOS после успешного завершения всей очереди может звучать сигнал. Переключатель находится в **«Настройки» → «Уведомления»**.

Кнопка **«Журнал»** открывает отдельное окно с последними записями. Закрытие окна не останавливает операции: при повторном открытии записи сохраняются. Переключатель «Показывать новые записи» управляет автопрокруткой. **«Экспорт диагностики…»** сохраняет версии компонентов и журнал с маскированием распознанных чувствительных данных. Перед публикацией просмотрите отчёт; автоматически он никуда не отправляется.

Если во время скачивания App Store вернул HTTP 401 из-за истёкшей сессии, очередь остановится. Войдите в тот же Apple Account и нажмите **«Продолжить оставшиеся»**. Готовые IPA повторно не скачиваются.

Если App Store вернул `empty songList`, он не предоставил данные для скачивания, а точная причина неизвестна. Два таких ответа подряд для разных приложений приостанавливают пакет. Проверьте скачивание в App Store под тем же аккаунтом. После недавней смены пароля войдите заново с новым паролем. Удалять кэш не нужно.

**«Скопировать диагностику…»** рядом с итогом открывает отчёт с маскировкой распознанных личных данных. Его можно просмотреть и скопировать.

Если iPhone не найден, проверьте USB, разблокировку, доверие и компоненты Apple; используйте **«Проверить драйвер»** и **«Помощь Apple»**. При других сбоях откройте подробности ошибки. В [обращении](https://github.com/iamdarkls/IPA-Desktop/issues) укажите версию IPA Desktop, ОС, архитектуру и шаги воспроизведения. Приложите проверенный диагностический отчёт.

## Аккаунт и данные

**«Проверить аккаунт»** проверяет сохранённую сессию. Для смены пользователя нажмите **«Выйти»**, затем войдите под нужным аккаунтом. Скачанные IPA сохраняются. После ошибки входа введите пароль заново; одна попытка ограничена пятью минутами.

Пароль и код 2FA не передаются в командной строке и не записываются в журнал или настройки оболочки. Встроенная защищённая сборка ipatool сохраняет токен сессии, но не сохраняет пароль Apple Account и не выполняет скрытый повторный вход.

Данные хранятся в папке `IPA-Desktop` пользовательского профиля (в Windows — `%LOCALAPPDATA%\IPA-Desktop`). Кнопка **«Папка IPA»** открывает подпапку `Apps` на любой платформе. В родительской папке хранятся `AppSets.json`, `state.json` и `operation-queue.json`.

### Защита Apple Account и кэш

На Windows текущая версия движка видна в главном окне. Если она устарела, нажмите «Обновить движок». Откат доступен в настройках. **ipatool-guard 1.3.4.1** собран из полного релиза Sorvigolova/ipatool 1.3.4 и использует его встроенный механизм подтверждения устройства. Отдельный AMD-патч из PR №5 и загрузка библиотек из Android-пакета больше не используются. На macOS и Linux этот движок входит в комплект IPA Desktop и обновляется вместе с приложением. Локальные IPA можно устанавливать без входа.

При скачивании IPA Desktop может переиспользовать исходный архив из `Cache/IPA`. App Store сначала подтверждает доступ для текущего аккаунта; только затем движок сверяет контрольную сумму и собирает отдельный IPA с данными этого аккаунта. Лимит кэша по умолчанию — 3 ГиБ. В настройках видно занятое место. Лимит 0 отключает использование кэша, сохраняя исходные архивы на диске. «Очистить кэш» удаляет их после подтверждения; готовые IPA остаются в библиотеке. Если копии нет, она повреждена или Apple не прислала контрольную сумму, IPA скачивается как обычно. Очередь показывает, откуда получен файл. Перед установкой IPA другого аккаунта можно подготовить копию той же сборки для текущего аккаунта, если известен её точный ID.

Движок использует сохранённый токен сессии, но не сохраняет пароль Apple Account в новых сессиях и не использует пароль из старых файлов. Скрытый вход после истечения сессии отключён. Неверный пароль и сетевые ошибки авторизации не повторяются внутри движка. Штатные перенаправления Apple и явный этап 2FA поддерживаются. При истечении сессии очередь останавливается, оставшиеся IPA остаются в выбранном.

Счётчик неправильных данных общий для всех аккаунтов и обновлённых копий IPA Desktop в одном профиле Windows. Три отказа за 24 часа включают общую паузу 10 минут; успешный вход другим аккаунтом и перезапуск счётчик не сбрасывают. После первого неверного ввода действует пауза 30 секунд, после второго — 2 минуты, после третьего и последующих — общая пауза 10 минут. Временные сетевые ошибки и ограничения сервера также останавливают очередь; более длинный `Retry-After` учитывается, если присутствует в выводе движка. Повторы выполняются только вручную.

При явной блокировке аккаунта все новые входы и загрузки останавливаются до ручного разбора. Восстановите доступ через Apple на доверенном устройстве, затем откройте **«Ограничения входа»**. Подтверждение снимает только ручной запрет программы, сохраняя паузы и счётчики. Проверка сохранённого аккаунта и выход не снимают запрет загрузок; требуется новый подтверждённый вход.

В состоянии защиты нет учётных данных. Диагностика входа показывает HTTP-статус, проверенный хост Apple, число перенаправлений и числовой код отказа. HTTP 204, сетевые сбои и отказ на этапе 2FA не создают паузу входа. Неизвестный ответ Apple не выдаётся за неверный пароль или доказанный бан IP. Старые версии приложения и сторонние клиенты не участвуют в общей блокировке запросов.

Эти меры уменьшают лишние обращения, но не гарантируют отсутствие блокировок Apple и не определяют срок ограничений по сети. Проверки авторизации выполняются с имитатором транспорта, без аккаунтов клиентов.

## Если iPhone не доверяет компьютеру

Перед установкой программа проверяет выбранный iPhone. При `Invalid HostID` она пробует восстановить сопряжение по USB: разблокируйте телефон, нажмите **«Доверять»** и введите код-пароль на самом iPhone. Ожидание видно в окне и отменяется кнопкой «Отмена». После подтверждения очередь продолжится с текущего IPA; успешные файлы повторяться не будут.

Если связь не восстановилась, очередь останавливается. Подключите нужный iPhone: после успешной фоновой проверки кнопки снова станут доступны. При необходимости нажмите **«Восстановить связь»**. Для восстановления доверия нужен комплект **device-tools 1.0.3+** из настроек. Установите актуальную версию IPA Desktop и инструментов. По Wi-Fi для пересопряжения требуется подключить USB. Ошибки показывают причину и действие, технический ответ остаётся в итоге операции.

## Структура проекта и сборка

| Каталог | Назначение |
|---|---|
| [Source](Source) | Domain, Infrastructure, Services и Presentation; внутри — каталоги по функциям |
| [MainWindow.axaml](MainWindow.axaml), [App.axaml](App.axaml) | Интерфейс Avalonia и общая тема |
| [Assets](Assets), [Tests](Tests), [Scripts](Scripts) | Иконки, проверки и сценарии сборки/обновления |
| [Tools/DeviceTools](Tools/DeviceTools) | Независимая сборка инструментов: модули, сценарии и тесты |
| [Docs](Docs), [changelogs](changelogs) | Архитектура и история выпусков |

Для разработки нужны Python 3 и .NET SDK из [global.json](global.json). Локальная проверка использует ту же точку входа, что и GitHub Actions. Пример для Linux x64:

```sh
python Scripts/desktop.py test --rid linux-x64
```

Для Windows используйте RID `win-x64`, для Mac — `osx-arm64` или `osx-x64`. Перед упаковкой macOS и Linux подготовьте нативные инструменты по [инструкции сборки](Docs/BUILD.md). CI проверяет автономный запуск из архива, загрузку нативных инструментов и миграцию данных. На macOS он также проверяет иконку и подпись после распаковки. Вход с личным Apple Account и установку на физический iPhone проверяют отдельно.
