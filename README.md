# IPA Desktop

**Поиск, скачивание и установка приложений для iPhone в Windows 10/11.**

В версии **0.2.8** добавлены фильтр локальных IPA по Apple Account, массовый выбор файлов текущего фильтра и счётчики списка и выбранного.

Графическая оболочка на C# и WPF от [iamdarkls](https://github.com/iamdarkls). Работает напрямую с **ipatool**, использует отдельный комплект инструментов для iPhone и сохраняет наборы приложений по App Store ID.

## Возможности

| Раздел | Возможности |
|---|---|
| Поиск и загрузка | Поиск по названию или ID, выбор версии, общая очередь из разных поисков |
| Файлы и устройство | Импорт IPA, названия приложений, версии и Apple Account, установка на выбранный iPhone |
| Выбранные IPA | Добавление двойным кликом, установка или удаление в корзину без Ctrl |
| Наборы и хранилище | Несколько наборов по ID, объединение без дублей, размер папки и выбор старых версий |
| Настройки | Звуки завершения, независимые обновления оболочки, ipatool и инструментов iPhone |
| Журнал | Прогресс операций, повтор ошибок, автопрокрутка и экспорт диагностики |

## Требования

- **Windows 10/11 x64**, .NET Framework **4.6 или новее**.
- Доступ к GitHub и сервисам Apple.
- Apple Account для скачивания приложений.
- Для установки: компоненты **Apple Mobile Device Support / Apple Mobile Device Service**, USB-кабель и доверие iPhone к компьютеру.

IPA Desktop запускается без установки. Распакуйте программу в папку с доступом на запись; запуск оболочки от администратора не требуется. Доступность приложений и возможность установки зависят от Apple Account, версии iOS и ответа сервисов Apple.

## Быстрый старт

1. Откройте [последний релиз](https://github.com/iamdarkls/IPA-Desktop/releases/latest) и скачайте **IPA-Desktop-<версия>-Windows.zip** из **Assets**.
2. Полностью распакуйте ZIP. Запустите **IPA-Desktop.exe**, сохранив остальные файлы и папки рядом.
3. Дождитесь получения **ipatool** и **инструментов для iPhone**. Если автоматическое обновление отключено, установите их во вкладке **«Настройки»**.
4. Нажмите **«Войти в Apple Account»** и завершите вход в консоли ipatool.
5. В **«Поиск и загрузка»** найдите приложения, добавьте их двойным кликом в выбранное и нажмите **«Скачать (N)»**.
6. В **«Файлы и устройство»** найдите iPhone, добавьте скачанные IPA в выбранное двойным кликом и нажмите **«Установить (N)»**.

## Вход в Apple Account

Почта, пароль и код двухфакторной аутентификации вводятся в консольном окне **ipatool**. После подтверждения сессии оболочка показывает аккаунт и блокирует кнопку входа.

- **«Проверить аккаунт»** — проверить текущую сессию.
- **«Выйти»** — завершить сессию перед сменой аккаунта.
- Для другого человека выйдите из своего аккаунта и войдите в его аккаунт перед скачиванием.

Хранением сессии занимается ipatool. Менеджера нескольких сохранённых аккаунтов в интерфейсе пока нет.

## Поиск и загрузка

Введите название или числовой **App Store ID** и нажмите **«Найти»** либо Enter. Поиск объединяет результаты каталога, пользовательского списка и App Store.

| Действие | Результат |
|---|---|
| Одинарный клик по строке | Только выделяет строку |
| Двойной левый клик | Добавляет приложение в выбранное снизу |
| «В выбранное» | Добавляет выделенные строки или обновляет выбранную версию |
| Крестик × | Убирает одно приложение из очереди |
| «Очистить» | Очищает выбранное и снимок последней загрузки |
| Очистка строки поиска | Убирает результаты поиска, сохраняя очередь |

Можно искать приложения с разными названиями по очереди: выбранное сохраняется между запросами. Повторы по ID не создаются. Ctrl/Shift остаются дополнительным способом выделить группу строк, но для наполнения очереди они не нужны.

### Выбор версии

По умолчанию скачивается последняя доступная версия. Чтобы выбрать другую:

1. Выделите одно приложение.
2. Нажмите **«Список версий»** и выберите идентификатор версии.
3. **«Таблица версий…»** открывает отдельное окно с ID, номером версии, минимальной ОС и платформами. Выделите строки (Ctrl / Shift), нажмите «Получить сведения», затем «Добавить выбранные в очередь». Сведения загружаются только по запросу, до 20 версий за раз, с прогрессом и отменой. Известные ID можно ввести вручную через запятую или пробел; доступность версии проверит Apple. В очереди могут находиться несколько версий одного приложения, крестик удаляет только выбранную копию. Наборы по-прежнему сохраняют только ID приложения, без привязки к версии или аккаунту.

**«Сведения»** покажет доступные номер и дату выпуска, минимальную версию ОС (ipatool 1.1.9+) и платформы (ipatool 1.2.0+). Новые сведения могут отсутствовать: движок получает их из пакета приложения по возможности, не скачивая IPA целиком. Отсутствие этих полей не подтверждает совместимость с вашим iPhone.
4. Нажмите **«В выбранное»**, чтобы закрепить версию для этого приложения.

**«Скачать (N)»** обрабатывает очередь последовательно. Для каждого скачивания создаётся отдельный IPA, чтобы не перезаписывать копии других версий или аккаунтов. Получение бесплатной лицензии выполняется через ipatool; ограничения Apple Account сохраняются.

### Скорость загрузки

Во время загрузки показываются проценты ipatool, записанный объём и **приблизительная скорость в МБ/с**. В режиме GUI ipatool 1.2.0 сообщает только процент, поэтому скорость измеряется раз в секунду по росту временного `.ipa.tmp` конкретной загрузки. Это скорость записи получаемого IPA, а не точный замер пропускной способности сети; кэширование и буферизация могут влиять на показания.

До появления двух измерений скорость не указывается. При остановке роста показатель снижается до нуля, при повторной загрузке счётчик сбрасывается. После 100% ipatool ещё может проверять и подготавливать IPA — дождитесь результата операции. Короткая загрузка может завершиться до первого измерения.

## Файлы и устройство

1. Подключите iPhone по USB, разблокируйте его и подтвердите **«Доверять этому компьютеру»**.
2. Нажмите **«Найти iPhone»** и выберите телефон. В списке отображается его имя; до обнаружения устройства кнопка поиска зелёная.
3. Выберите **Apple Account** над таблицей: все аккаунты, конкретный аккаунт или **«Без данных об аккаунте»**. Число в скобках — количество IPA. Этот фильтр не меняет аккаунт входа.
4. Добавьте нужные IPA **двойными кликами** или нажмите **«Выбрать все (N)»**, чтобы добавить все файлы текущего фильтра в нижний список выбранного.
5. Нажмите **«Установить (N)»** и проверьте устройство в подтверждении.

В таблице отображаются **короткое название приложения, версия, Apple Account и размер**. Полное имя файла и путь доступны в подсказке при наведении на название. Файлы на диске сохраняют уникальные имена. IPA с кириллицей устанавливаются через временное относительное ASCII-имя; оригинал сохраняется.

Apple Account читается из метаданных самого IPA. Если сведений нет, текущий аккаунт программы вместо них не подставляется. При установке копий для другого человека проверяйте этот столбец.

### Выбор и удаление без Ctrl

Установка и удаление используют **один нижний список выбранных IPA**. Он сохраняется при переключении аккаунта. Счётчик **«вне фильтра»** предупреждает о выбранных IPA других аккаунтов: они тоже входят в установку и удаление. Чтобы работать только с новым аккаунтом, сначала нажмите **«Очистить»**. Повторный массовый выбор не создаёт дубликатов.

Над таблицей отображаются количество видимых файлов, общее число IPA и размер текущего списка. Обновление сохраняет фильтр, пока этот аккаунт есть в папке. Если его файлы исчезли, показываются все аккаунты.

Действия с выбранным:

- Двойной клик добавляет файл, крестик × убирает его, **«Очистить»** сбрасывает список.
- **«Удалить выбранные IPA (N)»** расположена снизу рядом с установкой и перемещает именно эти IPA в корзину после подтверждения.
- Удаление файла с компьютера не удаляет приложение с iPhone. Для окончательного освобождения места очистите корзину Windows.

**«Добавить IPA…»** копирует внешние IPA в рабочую папку; **«Обновить файлы»** перечитывает её содержимое.

Выделите один IPA и нажмите **«Сведения об IPA…»** для просмотра версии, Apple Account, App Store ID, Bundle ID, размера и полного пути. **«Об iPhone…»** получает имя, ProductType, версию iOS и UDID выбранного телефона. В диалогах текст можно копировать.

Над таблицей показана проверка компонентов Apple. **«Проверить драйвер»** повторяет её, **«Помощь Apple»** открывает инструкцию. Запущенная служба сама по себе не гарантирует исправное USB-подключение: разблокировка и доверие телефона всё равно нужны.

### Установка по Wi-Fi (экспериментально)

1. Сначала подключите iPhone по USB и подтвердите доверие компьютеру.
2. В Apple Devices включите **«Показывать это устройство при подключении к Wi-Fi»** и примените настройки. В iTunes — **«Синхронизировать с этим iPhone по Wi-Fi»**. [Инструкция Apple](https://support.apple.com/guide/devices-windows/sync-content-over-wi-fi-mchl388b22c3/windows).
3. Компьютер и телефон должны быть в одной локальной сети. Отключите USB, разблокируйте iPhone.
4. Во вкладке «Файлы и устройство» включите **«USB + Wi-Fi (экспериментально)»** и нажмите **«Найти iPhone»**. Выберите подключение с подписью **Wi-Fi**.
5. Добавьте IPA в выбранное и нажмите «Установить».

При включённом Wi-Fi USB-поиск сохраняется; один iPhone может отображаться двумя строками с разными каналами. Перед каждой установкой проверяется связь по выбранному каналу. Автоматического переключения на USB или повторной установки при обрыве нет: сначала проверьте результат на телефоне, затем используйте «Повторить ошибки» при необходимости.

Если обнаружение не работает, проверьте сетевую синхронизацию, службу Apple Mobile Device, Bonjour, разрешения Apple в брандмауэре, VPN и изоляцию устройств в гостевой сети. Подсказка также доступна кнопкой «Wi-Fi: помощь». Программа сама не меняет настройки сети, брандмауэра и доверия. На физическом устройстве новый режим ещё не проверен.

Перед установкой читается Info.plist фактически отправляемого IPA (XML или binary): неподходящая платформа либо требование более новой iOS останавливают этот элемент с понятной ошибкой. Если сведений недостаточно, это отмечается в журнале, окончательное решение принимает iPhone. Минимальная версия ОС и платформы доступны в «Сведения об IPA…».

## Наборы приложений

Набор хранит **App Store ID и названия** — без Apple Account, телефона, локальных IPA и закреплённых версий. Его можно использовать после смены аккаунта и устройства.

### Создать или дополнить

В **«Поиск и загрузка»** добавьте приложения в выбранное, в поле **«Набор»** введите новое имя или выберите существующее и нажмите **«Добавить в набор»**. Существующий набор дополняется без повторов по ID.

В разделе **«Наборы и хранилище»** кнопка **«Сохранить из поиска»** делает то же самое. После загрузки доступен снимок последней очереди, пока не нажато **«Очистить»**. Добавление из локальных IPA в интерфейсе отсутствует.

### Редактировать набор

Отметьте один набор и нажмите **«Редактировать набор…»**. В отдельном диалоге можно изменить имя, обычными кликами отметить приложения и убрать их кнопкой **«Убрать отмеченные»**. Изменения записываются только после **«Сохранить»**. **«Отмена»** сохраняет исходный набор. Нельзя сохранить пустой набор или переименовать его в уже существующий.

### Использовать несколько наборов

1. Откройте **«Наборы и хранилище»**.
2. Обычными кликами отметьте один или несколько наборов.
3. Проверьте предпросмотр и нажмите **«В очередь скачивания»**.
4. Перейдите к скачиванию под нужным Apple Account, затем установите новые IPA на нужный iPhone.

Приложения объединяются без дублей. Если версия приложения уже выбрана вручную, добавление набора её сохраняет. Хранится до **100 наборов**, до **500 приложений в каждом**. Удаление набора убирает только список, сохраняя IPA.

Старые наборы с именами файлов преобразуются по метаданным исходных IPA. Если файл или ID недоступен, пересоздайте набор через поиск.

## Хранилище IPA

В **«Наборы и хранилище»** отображаются число файлов и занятое место.

**«Выделить старые версии»** ищет более старые числовые версии одного приложения отдельно для каждого Apple Account. Без надёжных сведений файл не помечается старым; одинаковые версии автоматически не удаляются.

Проверьте выделенные строки и нажмите **«Удалить выбранные копии»**. Удаление выполняется в корзину после подтверждения.

## Прогресс, повтор ошибок и звуки

Внизу окна показаны текущее приложение и положение в очереди. Проценты, объём и скорость отображаются только при наличии данных в выводе утилиты; отсутствующие значения не вычисляются приблизительно.

- **«Повторить ошибки»** запускает только неудачные элементы. Для скачивания сохраняется выбранный ID версии; для установки проверьте выбранный iPhone.
- **«Сбросить ошибки»** очищает список повтора, сохраняя файлы и выбранное.
- **«Отмена»** останавливает текущую операцию. Завершённые операции не откатываются, ещё не запущенные не считаются ошибками.
- После завершения всей очереди скачивания или установки **без ошибок** звучит один системный сигнал Windows.

Звук включается и отключается в **«Настройки» → «Открыть настройки…» → «Уведомления»**. По умолчанию он включён; выбор сохраняется после перезапуска. Громкость и сам системный звук зависят от настроек Windows.

Очереди и списки ошибок действуют в текущем сеансе. Для повторного использования списка приложений сохраняйте наборы.

## Настройки и обновления

Во вкладке **«Настройки»** находятся уведомления и три независимых блока:

| Компонент | Источник | Обновление |
|---|---|---|
| IPA Desktop | [iamdarkls/IPA-Desktop Releases](https://github.com/iamdarkls/IPA-Desktop/releases) | «Проверить версию» → «Обновить до …» |
| ipatool | [Sorvigolova/ipatool Releases](https://github.com/Sorvigolova/ipatool/releases) | «Проверить обновления» |
| Инструменты для iPhone | Наши релизы **device-tools-v…** в [iamdarkls/IPA-Desktop](https://github.com/iamdarkls/IPA-Desktop/releases) | «Проверить инструменты» |

Проверки при запуске включаются отдельно. Обновление программы выполняется после подтверждения и перезапуска; скачанные IPA и настройки сохраняются. Архивы проверяются по размеру и SHA-256.

**«Откатить движок»** возвращает предыдущий ipatool и отключает его автообновление. **«Откатить комплект»** аналогично возвращает инструменты для iPhone. Эти компоненты обновляются независимо друг от друга.

Комплект для iPhone собирается из закреплённых исходников **libimobiledevice** и **ideviceinstaller** с необходимыми DLL. GitHub Actions ежедневно проверяет стабильные выпуски исходных проектов: новый комплект публикуется после успешной сборки и проверок, с исходниками, лицензиями и чейнджлогом. Подробнее: [Device Tools](Tools/DeviceTools/README.md).

Из **IPA Downloader** используется только каталог приложений: он обновляется при поиске и кэшируется. Его скрипты и комплект инструментов для работы актуальной версии IPA Desktop не нужны.

## Видимые ошибки и итог операции

После очереди над прогрессом появляется постоянная плашка результата. Ошибка выделяется цветом, показывает приложение и краткую причину и остаётся видимой при смене вкладки.

- **«Подробнее…»** — диалог со списком успешных и неудачных приложений, полными исходными ошибками и кнопкой копирования.
- **«Повторить ошибки»** — повтор только неудачных действий; при установке требуется выбранный iPhone и подтверждение.
- **«×»** — скрыть плашку. Последний отчёт остаётся доступен верхней кнопкой **«Итог операции»**.

Ошибки также записываются в журнал. Итоги хранятся в текущем сеансе; для сохранения технических записей используйте экспорт диагностики.

## Журнал и диагностика

Журнал автоматически показывает последние записи при открытии вкладки и прокручивается при поступлении новых сообщений. Во время длительной операции появляются сообщения о времени работы и отсутствии нового вывода.

**«Экспорт диагностики…»** сохраняет текстовый отчёт с версиями компонентов и журналом. Перед записью маскируются распознанные почтовые адреса, секреты и данные устройств. Отчёт автоматически никуда не отправляется; перед публичной публикацией просмотрите его содержимое.

## Где хранятся данные

Основная папка: **%LOCALAPPDATA%\IPA-Desktop**.

| Данные | Путь относительно основной папки |
|---|---|
| Скачанные и импортированные IPA | `Apps` |
| Версии ipatool и инструментов iPhone | `Versions` |
| Сохранённые наборы | `AppSets.json` |
| Настройки, включая звуки | `state.json` |
| Пользовательский каталог | `Files/AppsListCustom.txt` |
| Подготовленные обновления программы | `GuiUpdates` |

Формат пользовательского каталога — одна запись на строку:

```text
Название приложения: App Store ID
```

Сессией Apple Account управляет ipatool отдельно от этих настроек.

## Если что-то не работает

| Ситуация | Что сделать |
|---|---|
| Одинарный клик не добавляет в выбранное | Используйте двойной левый клик или кнопку «В выбранное» |
| iPhone не найден | Проверьте USB, разблокировку, доверие и службу Apple; повторите поиск |
| Ошибка скачивания | Проверьте сессию аккаунта, доступность приложения и журнал ipatool |
| Ошибка установки | Посмотрите ответ установщика в журнале, проверьте IPA и совместимость с iOS |
| Ошибка `zip_open … : 18` в старой версии | Обновите IPA Desktop: обработка кириллицы исправлена начиная с 0.1.22; IPA заново скачивать не требуется |
| Долго нет нового вывода | Посмотрите журнал; при необходимости отмените операцию и повторите |
| Нет сигнала завершения | Проверьте «Настройки» → «Уведомления», громкость Windows и отсутствие ошибок в очереди |
| Не работает автообновление | Проверьте доступ к GitHub и запись в папку программы либо распакуйте свежий ZIP вручную |

Для [сообщения об ошибке](https://github.com/iamdarkls/IPA-Desktop/issues) укажите версию программы, Windows и инструментов, шаги воспроизведения и приложите проверенный диагностический отчёт.

## Разработка

C# / WPF / .NET Framework. Код разделён на слои **Domain**, **Infrastructure**, **Services** и **Presentation**.

| Папка | Содержимое |
|---|---|
| [Source](Source) | Исходные классы, модели и контроллеры |
| [Generated](Generated) | Переносимые снимки исходников для компиляции |
| [Assets](Assets) | Иконки и исходник SVG |
| [Tests](Tests) | Проверки компонентов, интерфейса и обновлений |
| [Scripts](Scripts) | Синхронизация исходников, упаковка и обновление |
| [Tools/DeviceTools](Tools/DeviceTools) | Сборка инструментов для iPhone |
| [Docs](Docs) | [Архитектура и инструкции для разработчиков](Docs/ARCHITECTURE.md) |
| [changelogs](changelogs) | Описание выпусков на русском |

После изменения классов обновите снимки и соберите программу:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Scripts/Sync-Sources.ps1
.\Build.cmd
```

Используется штатный компилятор .NET Framework; Visual Studio и NuGet для этой сборки не требуются. GitHub Actions выполняет проверки на Windows, собирает ZIP и публикует Releases. Для выпуска нужен чейнджлог соответствующей версии. Установка на физический iPhone требует отдельной проверки с устройством.
