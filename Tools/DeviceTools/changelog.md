## IPA Desktop Device Tools 1.0.8

- Сохранены libplist 2.8.1 с исправлениями разбора plist и libtatsu 1.1.0.
- Добавлен ipa-device-events: подписка на подключение, отключение и сопряжение через API libimobiledevice. Процесс передаёт только сигнал изменения, без UDID; закрытие входного канала освобождает подписку.
- Добавлен device-tools.json: версия комплекта, платформа, протокол событий и точные версии/ревизии библиотек, сформированные из входов сборки.
- Контрольные суммы, автономный запуск утилит, исходники и лицензии включены. Прежние комплекты сохранены для отката.

Для прежних IPA Desktop сохранён обычный Windows-x64.zip с четырьмя EXE. Windows-x64-Events.zip содержит дополнительный helper; его выбирают новые клиенты. Оба архива имеют собственные корректные манифесты и контрольные суммы.
