# Установка IPA Desktop 1.0

| Система | Архив | Минимальная среда |
|---|---|---|
| Windows x64 | Windows.zip | Windows 10 1809+ / Windows 11, компоненты Apple |
| macOS Apple Silicon | macOS-arm64.zip | macOS 15+ |
| macOS Intel | macOS-x64.zip | macOS 15+ |
| Linux x64 | Linux-x64.zip | Ubuntu 24.04 / glibc 2.39+, графический сеанс X11 или XWayland |

Все архивы самодостаточны по .NET. Настройки, IPA, сессии и очередь остаются в профиле пользователя, отдельно от папки приложения. Профили и ключи шифрования ipatool привязаны к компьютеру: не копируйте сессию между ОС, войдите заново. Не запускайте программу через sudo.

## Windows

Распакуйте полный архив, запустите IPA-Desktop.exe. Для подключения iPhone установите Apple Devices или Apple Mobile Device Support. Прежние настройки и IPA сохраняются, включая обновление с 0.2.12. Движок и инструменты обновляются отдельно в настройках.

## macOS

Выберите arm64 для M1/M2/M3/M4 и последующих Apple Silicon, x64 для Intel. Распакуйте и перенесите IPA-Desktop.app в папку приложений пользователя. Откройте приложение, подключите и разблокируйте iPhone, подтвердите доверие. Драйверы Apple встроены в macOS.

Сборка подписана ad-hoc для загрузки нативных библиотек, но не заверена Apple Developer ID/notarization. При блокировке открытия проверьте источник архива и разрешите запуск через «Системные настройки → Конфиденциальность и безопасность». Защиту системы целиком отключать не требуется.

## Linux

Распакуйте полный архив с сохранением прав и запустите IPA-Desktop/IPA-Desktop. Если архиватор сбросил права: `chmod +x IPA-Desktop/IPA-Desktop IPA-Desktop/native/ipa-pty IPA-Desktop/native/ipatool IPA-Desktop/native/idevice*`.

В Ubuntu установите системное подключение и базовые библиотеки рабочего стола:

```sh
sudo apt install usbmuxd libimobiledevice-utils libglib2.0-bin libx11-6 libice6 libsm6 libfontconfig1
```

usbmuxd должен обслуживать USB-подключение. Пакеты дистрибутива также дают правила udev; при нехватке прав проверьте правила для вашего устройства и переподключите iPhone. Не используйте chmod 777 и не запускайте GUI от root. Конкретные команды установки для других дистрибутивов могут отличаться. Встроенные инструменты приложения не заменяют системную службу usbmuxd.

Для корзины используется gio, входящий в libglib2.0-bin. При недоступной корзине программа сообщает ошибку, а не удаляет файл окончательно. В Wayland используется XWayland; headless-сервер без графической сессии не предназначен для GUI.

## Обновление и инструменты

На macOS/Linux полный набор инструментов поставляется с приложением: тот же защищённый ipatool 1.2.1.1 и закреплённые исходники device-tools с патчем placeholder. Отдельное обновление/откат Windows-комплектов на этих ОС не применяется. Проверка версии приложения остаётся в настройках.

Встроенное обновление выбирает архив по ОС и архитектуре, проверяет источник, размер и SHA-256, ожидает закрытия программы, заменяет папку установки и сохраняет предыдущую копию рядом. Папка установки должна быть доступна на запись пользователю; иначе распакуйте новую версию вручную. На macOS перед обновлением скопируйте .app из образа/архива в обычную папку, не запускайте из временного просмотра архива.

## Проверки и ограничения

Для каждого выпуска проверяются сборка, все существующие тесты (включая приватный терминал входа), запуск упакованного самодостаточного GUI, сохранение настроек/наборов/очереди, профиль защиты движка и команды инструментов без аккаунтов Apple. Проверка сопряжения и установки на физическом iPhone должна выполняться отдельно на целевых системах. Наличие приложения в истории покупок не гарантирует доступность его загрузки у Apple.
