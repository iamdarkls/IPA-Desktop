## Проверки исправлений

- `Tests/Verify-Services.ps1`: HTTP-сбой с локальным кэшем, ограничение повторов, восстановление запроса, явная отмена; атомарный импорт, конфликт имени, очистка временного файла и отмена внутри копирования.
- `Tests/Verify-AppleLogin.ps1`: фрагментированные ANSI-запросы, варианты регистра/пробелов, перерисовки, порядок этапов и отсутствие повторной отправки секретов.
- `Tests/Verify-Layout.ps1`: автоматическая синхронизация изменённого Source при сборке, а также сборка переносимого пакета без Source.
- `PYTHONPATH=Tools/DeviceTools python -m unittest discover -s Tools/DeviceTools/Tests -v`: автономные проверки device-tools.

Полный вход с личным Apple Account и установка на физический iPhone требуют отдельной проверки на Windows и устройстве; автоматические проверки не заменяют эти сценарии.
