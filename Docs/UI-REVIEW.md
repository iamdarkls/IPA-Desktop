# Обзор интерфейса IPA Desktop

Проверены все пять вкладок MainWindow.xaml и их контроллеры. Это предложения для следующих изменений; реализованные в 0.2.7 перечислены отдельно.

## Реализовано в 0.2.7

Во «Файлы и устройство» появились фильтр по Apple Account, число и размер видимых IPA, массовое добавление текущего списка и подсказка для пустой папки. Выбор сохраняется между аккаунтами, скрытые выбранные файлы учитываются отдельно. Подтверждения операций различают версии и аккаунты копий.

## Что упростить следующим

| Место | Что мешает | Предлагаемое изменение |
|---|---|---|
| Общая шапка | Пять служебных кнопок занимают высоту во всех вкладках | Компактный блок текущего аккаунта с меню «Проверить / Выйти», доступ к папке рядом с локальными файлами; важные действия остаются видимыми |
| Поиск и загрузка | Одновременно показаны список версий, отдельная таблица, сведения и несколько действий | Оставить основной сценарий «Найти → Выбрать → Скачать», выбор версий объединить в кнопку «Версии…» с существующей таблицей |
| Выбранные приложения | Длинная горизонтальная лента неудобна для десятков файлов; одинаковые названия трудно различить | Раскрываемая очередь с названием, версией, аккаунтом для локальных IPA, размером и удалением строки; в свёрнутом виде — счётчик и основное действие |
| Файлы и устройство | Одинарное выделение строки и выбранное снизу выглядят как два разных выбора | Добавить отдельный столбец с флажками очереди и заметное состояние «Уже выбрано»; сохранить двойной клик и кнопку массового выбора |
| Файлы и устройство | При большом числе IPA сложно найти файл даже после фильтра аккаунта | Поиск по названию, версии и Bundle ID внутри локального списка; «Выбрать все» учитывать оба фильтра |
| Подключение iPhone | Драйверы, помощь Wi-Fi и список устройств конкурируют с действиями над IPA | Сгруппировать подключение отдельной компактной карточкой с именем телефона, iOS, USB/Wi-Fi и состоянием; подробную проверку компонентов раскрывать по запросу |
| Наборы и хранилище | Две самостоятельные задачи делят ширину одной вкладки; сохранение из поиска дублируется | Разделить внутри вкладки на страницы «Наборы» и «Хранилище», оставив добавление в набор непосредственно в поиске |
| Наборы | Выбор нескольких наборов опирается на стандартное выделение списка | Явные флажки, счётчик выбранных наборов и предпросмотр объединённой очереди без повторов |
| Хранилище | Нет локального поиска и фильтра аккаунта; для группового удаления нужен Ctrl | Использовать тот же фильтр аккаунта и флажки, показывать общий размер выбранного перед удалением |
| Настройки | Три механизма обновления оформлены неодинаково | Одинаковые карточки «Программа / ipatool / Инструменты iPhone» с установленной версией, состоянием проверки, обновлением и откатом; настройки оставить в основной вкладке |
| Журнал | Технический поток удобен для диагностики, но хуже подходит для повседневного контроля | Добавить фильтр «Все / Ошибки / Предупреждения» и поиск; плашку ошибки и последний отчёт сохранять независимо от журнала |
| Прогресс | Видна текущая операция, но весь состав пакета находится в других местах | Кнопка «Открыть очередь» рядом с прогрессом, строки «Ожидает / Выполняется / Готово / Ошибка» и повтор ошибок на месте |

## Порядок внедрения

1. Флажки выбора и раскрываемая очередь: одинаковое поведение поиска и локальных файлов, явные версии и аккаунты, без запуска установки по клику строки.
2. Локальный поиск и единый выбор в хранилище: использовать готовый снимок IPA без повторного чтения файлов при вводе.
3. Упростить управление версиями и подключением, затем разделить наборы и хранилище.
4. Унифицировать настройки и добавить фильтры журнала.

Для каждого этапа проверять 940×720, масштаб Windows 125–150%, длинные названия и адреса аккаунтов, пустые списки и блокировку действий во время операции. Смена фильтров не должна незаметно менять очередь, а установка и удаление должны явно показывать её состав.
