# IPA Desktop 0.3.8

- Приложение пересобрано с .NET 10.0.14 и SDK 10.0.403, включающими внеплановое исправление безопасности Brotli. Обновлены System.Windows.Extensions и System.ServiceProcess.ServiceController до 10.0.14.
- Обновлён HarfBuzzSharp до 8.3.1.5; Avalonia 12.1.4 и DataGrid 12.1.2 сохранены как текущие стабильные версии.
- Обновлены Test SDK до 18.11.0, адаптер Visual Studio до 4.0.1 и GitHub Actions. Ядро xUnit 3.2.2 сохранено для совместимости с текущим Avalonia.Headless.XUnit. Сохранены проверки запуска готового EXE и совместимости обновления со старыми версиями.
- Новый ipatool-guard 1.2.0.2 пересобран с актуальными библиотеками MinGW-w64; патч защиты авторизации сохранён. Также доступен пересобранный комплект device-tools 1.0.4.
- Паузы 30 секунд / 2 минуты / 10 минут, ручной запрет при блокировке Apple и сохранение состояния защиты не изменены.

После обновления приложения обновите движок и инструменты iPhone в настройках. Обращения к Apple в тестах авторизации заменены имитаторами, аккаунты клиентов не используются.
