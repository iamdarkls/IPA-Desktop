# IPA Desktop 1.2.0

- Обновлены инструменты iPhone на всех платформах: libplist 2.8.1 с исправлениями обработки памяти и некорректных plist, libtatsu 1.1.0. Windows получает отдельный комплект device-tools 1.0.8; macOS/Linux — встроенный комплект нового выпуска.
- В карточке выбранного iPhone показаны ProductType, iOS и свободное место, если устройство его сообщает. При смене телефона и отключении устаревшие сведения очищаются.
- Перед передачей IPA проверяется доступ к службе установки. Если известного свободного места меньше размера распакованных файлов Payload, установка останавливается с понятным сообщением. Дополнительное место и окончательные требования определяет iOS.
- Обнаружение использует события libimobiledevice через изолированный ipa-device-events. Сигнал не содержит UDID; завершение освобождает подписку. При недоступности событий сохраняется поиск каждые 3 секунды, при активной подписке — контрольная проверка раз в 30 секунд.
- Фоновый процесс останавливается перед рабочими операциями и обновлением инструментов; общий жизненный цикл приложения дожидается его очистки.
- Состав комплекта формируется из точных входов сборки в device-tools.json: версия, платформа и ревизии библиотек. Убрана устаревшая подпись device-tools 1.0.5 на Unix.
- В настройках видны описание доступного обновления и результат проверки контрольной суммы/запуска после установки. Состав установленного комплекта включён в очищаемую диагностику. Windows-архив без Events сохраняет совместимость с прежними клиентами; новые клиенты выбирают отдельный Events-архив. Старые комплекты можно откатывать; при отсутствии нового helper используется резервный поиск.

Проверки на физическом iPhone остаются отдельным этапом: автоматические проверки используют фиктивное устройство и транспорт без запросов к Apple Account.
