- Фирменная иконка IPA Desktop добавлена в приложение для macOS. Finder и Dock используют её для обеих сборок Mac.
- При запуске из временной папки macOS или при недоступной папке установки обновление сразу объясняет, как перенести приложение в «Программы». При сбое загрузки показывает сообщение GitHub.
- Исправлена упаковка macOS. Архив сохраняет подпись приложения, а проверка повторно сверяет её после распаковки.
- Добавлены плавное переключение вкладок и появление уведомлений о подключении и результатах операций.
