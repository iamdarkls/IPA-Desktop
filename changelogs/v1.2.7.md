- Если App Store возвращает тот же исходный архив, IPA Desktop использует кэш и собирает отдельный IPA для текущего аккаунта без повторного скачивания.
- Кэш ограничен 3 ГиБ. При несовпадении контрольной суммы или отсутствии локальной копии работает обычное скачивание.
- Для кэша нужен движок ipatool-guard 1.3.1.2. На Windows его можно обновить из главного окна; в пакеты macOS и Linux он уже входит.
