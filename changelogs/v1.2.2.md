# IPA Desktop 1.2.2

- Windows: добавлена поддержка нового локального входа в App Store и обновлённого протокола скачивания. После обновления приложения установите движок 1.2.1.3 в настройках и войдите заново.
- При первом входе движок скачивает и проверяет файлы для авторизации. Пароль не сохраняется, а сетевые ошибки не вызывают автоматической повторной отправки пароля.
- На macOS и Linux движок не изменился.
