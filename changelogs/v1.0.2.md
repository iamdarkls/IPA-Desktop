# IPA Desktop 1.0.2

- Исправлено наложение индикатора выбранной вкладки на счётчик очереди: линия и содержимое заголовка теперь расположены в отдельных строках.
- Иконки, подписи и счётчики используют общий компонент с одинаковым выравниванием. Счётчик автоматически расширяется и обновляется при выполнении очереди.
- Объединено обновление таблиц локальных IPA и хранилища с сохранением выделения по пути файла. Обновлённые метаданные заменяют старые строки, исчезнувшие файлы снимаются с выделения.
- Проверены компактное окно 940×720, масштабы раскладки 100%, 125%, 150%, 200%, четырёхзначный счётчик и переключение всех вкладок.
- Проверки перед выпуском: 78 тестов приложения (с пропуском платформенных сценариев на других ОС), 3 проверки кеша, запуск готовых пакетов Windows, macOS arm64/x64 и Linux x64.
