- Журнал различает чтение сессии, запрос данных загрузки и получение IPA. Два пустых ответа App Store подряд для разных приложений приостанавливают очередь.
- После обрыва «Продолжить оставшиеся» сверяет версию и сборку на том же iPhone. Подтверждённые приложения пропускаются, остальные остаются на ручной повтор.
- Из итога можно перейти к следующему клиенту или открыть диагностику для копирования с маскировкой личных данных.
- Оптимизированы чтение списка IPA при возобновлении и обновление библиотеки при скачивании. README обновлён для Windows, macOS и Linux.
