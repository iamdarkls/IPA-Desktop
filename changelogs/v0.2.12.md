# IPA Desktop 0.2.12

- Импорт больших IPA можно отменить во время копирования. Неполный файл не появляется в списке IPA, временная копия удаляется при отмене или ошибке; существующие файлы не заменяются.
- После сбоя обновления каталога следующий поиск повторяет запрос через 30 секунд без перезапуска программы. Между попытками используется сохранённый каталог.
- Вход распознаёт поддерживаемые варианты регистра, пробелов и названий запросов email/Apple Account и 2FA, сохраняя порядок этапов и запрет повторной отправки секретов.
- Сборка из репозитория автоматически синхронизирует Source и Generated. Переносимый пакет по-прежнему собирается без Source.
- Windows-проверки запускаются также для pull request без публикации релиза. Добавлены регрессионные проверки импорта, восстановления каталога, запросов входа и автоматической синхронизации сборки.
- Проверены изменения IPA_Downloader 4.2.4/4.3.0 и все шесть upstream-проектов device-tools; закреплённые ревизии актуальны. Подробности: `Docs/UPSTREAM-REVIEW-2026-10-23.md` в репозитории.
