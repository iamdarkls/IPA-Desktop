# IPA Desktop 0.4.1

- Обновление движка в настройках теперь устанавливает ipatool-guard 1.2.1.1 на основе Sorvigolova/ipatool 1.2.1.
- В движок включено исправление аварийного завершения авторизации при включённой Windows Control Flow Guard (CFG): обновлён механизм возврата из эмуляции Unicorn для сборки MinGW. Системную защиту Windows отключать не требуется.
- Сохранены запрет скрытого входа, отсутствие сохранённых паролей, запрет повторных POST при неопределённом результате, защитные паузы 30 секунд / 2 минуты / 10 минут и ручной запрет после подтверждённой блокировки Apple.
- Перед публикацией сборка проверяет реальный Unicorn в отдельном процессе с включённой CFG без запросов к Apple. Архив движка содержит результат проверки, точные версии библиотек, исходники и лицензии.

После обновления IPA Desktop нажмите «Проверить обновления» в разделе «Движок ipatool». Отдельный комплект device-tools обновлять для этого исправления не нужно.
