- IPA Desktop проверяет обновления и обновляет каталог в фоне. Сохранённым каталогом можно пользоваться во время загрузки новой копии.
- В главном окне видна версия движка. На Windows для устаревшей версии появляется кнопка «Обновить движок»; откат доступен в настройках.
- В сборки для macOS и Linux входит защищённый движок ipatool 1.3.1.1 на основе Sorvigolova/ipatool 1.3.1.
- Кэш метаданных IPA различает файлы с именами, которые отличаются только регистром на файловых системах, где это поддерживается.
