# IPA Desktop 0.3.1

- Обновлён интерфейс: отдельная карточка iPhone, компактные действия с файлами, единый вид основных/опасных кнопок и понятные сообщения об ошибках прямо в окне.
- Перед установкой проверяются доверие и идентификатор выбранного iPhone. Invalid HostID распознаётся до передачи IPA.
- Программа пробует восстановить сопряжение только с выбранным UDID по USB. Устаревшая запись пересоздаётся адресно, без удаления сопряжений других устройств.
- Во время ожидания видно, что нужно разблокировать iPhone, подтвердить «Доверять» и ввести код-пароль на телефоне. Проверка ограничена 90 секундами и отменяется кнопкой «Отмена».
- После успешного сопряжения текущий IPA повторяется один раз, затем очередь продолжается. При потере связи или неудачном восстановлении очередь останавливается; остальные IPA не запускаются, успешные не повторяются. Повтор заблокирован до проверки связи.
- Ошибки доверия, блокировки, соединения, подписи, совместимости, свободного места и Apple Account переведены в сообщения с причиной и действием. Для смены пароля и empty songlist показаны отдельные инструкции; исходный ответ сохранён в отчёте.
- Для сопряжения нужен комплект device-tools 1.0.3 или новее с idevicepair. По Wi-Fi программа предлагает восстановить доверие через USB без незаметного переключения устройства.
