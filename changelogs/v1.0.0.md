# IPA Desktop 1.0.0

Первый выпуск для Windows, macOS и Linux.

- Windows x64: сохранены защищённый вход, автоматическое обновление, отдельные комплекты инструментов и совместимость обновления со старыми версиями.
- macOS 15+ для Apple Silicon (arm64) и Intel (x64): отдельные .app-сборки со встроенными ipatool и инструментами iPhone.
- Linux x64: сборка для Ubuntu 24.04 и совместимых систем с glibc 2.39+, встроенными инструментами и подключением через системный usbmuxd.
- Вход на macOS/Linux использует приватный PTY: пароль и 2FA не попадают в аргументы процессов, настройки или журнал. Защитные паузы и ручной запрет после блокировки сохранены.
- Адаптированы пути, запуск процессов, сопряжение и установка IPA, системная корзина и обновление приложения для каждой ОС. На macOS/Linux инструменты обновляются вместе с программой.
- Все платформы получают один интерфейс, очередь, наборы, историю покупок, прокси и проверку результата установки.
- Сборки и проверка готового приложения выполняются на каждой целевой ОС; исходники нативных компонентов приложены отдельными архивами.

.NET устанавливать не требуется. Для первого подключения на Linux нужны usbmuxd, правила udev и разрешения на USB. Подробности установки и ограничений — в Docs/PLATFORMS.md. macOS-сборки подписаны ad-hoc, без Apple Developer ID и нотариального заверения; система может попросить разрешить открытие в настройках безопасности.

Сценарии на физических iPhone требуют проверки на реальных устройствах; автоматические проверки не подменяют этот этап.
