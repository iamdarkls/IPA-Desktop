# IPA Desktop 0.3.0

- Интерфейс перенесён с WPF на Avalonia 12, приложение — с .NET Framework на .NET 10. Текущий выпуск поддерживает Windows x64; macOS и Linux будут отдельным этапом.
- Сохранены поиск, выбор версий, очереди, повтор ошибок, наборы, фильтры аккаунтов IPA, хранилище, автоопределение iPhone, установка USB/Wi-Fi, журнал и независимые обновления компонентов.
- Окна входа, 2FA, сведений, подтверждений и редактирования наборов работают асинхронно. Пароль и код маскируются и очищаются после отправки.
- Сохранены папка IPA, форматы настроек/наборов и установленные инструменты. JSON переведён на System.Text.Json с сгенерированными метаданными.
- Windows ZIP включает автономный EXE с .NET 10; отдельная установка runtime не требуется. Проверяется совместимость обновления с 0.2.12.
- Сборка выполняется SDK-проектом напрямую из Source; Generated, ручная синхронизация и старые WPF-сценарии сборки удалены.
- Добавлены headless-проверки Avalonia, снимки всех вкладок и проверки опубликованного EXE, старого/нового helper, входа ConPTY и настоящих инструментов Windows.
