# IPA Desktop 0.5.2

- Обновлены Avalonia, Desktop, Fluent и Headless до 12.1.5.
- Обновлены SkiaSharp до 4.154.0 и HarfBuzzSharp до 14.2.1.400 вместе с нативными библиотеками Windows, macOS, Linux и WebAssembly.
- Обновлены MicroCom.Runtime до 0.11.7 и Tmds.DBus.Protocol до 0.95.2.
- Обновлены совместимые вложенные зависимости тестового проекта и xunit.analyzers 2.2.0; тестовые пакеты не входят в приложение.
- Сборка использует actions/setup-dotnet 6.1.0. .NET SDK 10.0.403/runtime 10.0.14 и компоненты iPhone уже соответствуют актуальным стабильным выпускам.

xUnit оставлен на 3.2.2 с Microsoft.Testing.Platform 1.9.1: Avalonia.Headless.XUnit 12.1.5 несовместим с изменённым API обнаружения тестов xUnit 4.0.2 (MissingMethodException в GetTestCaseDetails). Проверки интерфейса сохранены; причины ограничений описаны в DEPENDENCIES.md.
